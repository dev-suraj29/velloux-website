## 1. Project
- **What:** Multi-page marketing site for **Velloux**, a web design & development studio in Kharadi, Pune, India (owner: Suraj, designer + developer).
- **Goal:** Win enquiries from Pune/India businesses (clinics, IT services, astrology/wellness, startups). First 3 seconds must hook the visitor (people rarely scroll past a dull hero).
- **Optimisation targets:** SEO + AEO (answer engines / featured snippets / voice) + GEO (generative engines like ChatGPT, Perplexity, and local Pune search). Pages must be easy to crawl and index.
- **Stack:** Static HTML generated by Python (`build/build.py`), Tailwind CSS 3 (compiled, no CDN), GSAP 3.12 (CDN, deferred), Font Awesome 6 (CDN), Google Fonts (Fraunces, Inter, JetBrains Mono). No framework, no database.

## 4. Build
```bash
python3 build/build.py                                                                  # regenerate pages + sitemap/robots/llms
npx tailwindcss -c build/tailwind.config.js -i build/input.css -o assets/css/tailwind.css --minify   # rebuild CSS (needed when new utility classes are used)
# or:  npm i && npm run build
```
Deploy: any static host (Netlify, Vercel, Cloudflare Pages, S3). Links are relative and use `.html`, so the folder also opens locally by double-click. If the host strips `.html`, keep canonicals as-is (they include `.html`) or update `head()` in build.py.

## 5. Design system
- **Palette:** ink `#06080B` (bg) · inkCard `#0C1116` · bone `#F3EFE6` (text) · mint `#7CE0C0` (primary accent/CTA) · mintDeep `#3E9A7C` · blue `#5B7FE0` · amber `#E7A64C` (highlight).
- **Type:** Fraunces (display serif), Inter (body), JetBrains Mono (labels, data). Display headings `font-display font-semibold`.
- **Motion:** (1) Preloader ~1.3s, wordmark + progress + curtain wipe, **once per session**, waits for fonts, failsafe 4.5s. (2) Home hero ~3s sequence: headline mask-reveal, stopwatch to 3.0s, code types → page renders → score rings to 100. (3) Inner pages: headline mask-reveal. (4) Scroll reveals (GSAP ScrollTrigger). (5) CSS cross-page view transitions (`@view-transition`).
- **Motion safety:** skipped for `prefers-reduced-motion` and for bots/crawlers (UA test) so content is always visible. `.js .hero-in / .line-inner` start hidden only when JS is on.
- **Components:** `glass-panel` cards, `scroll-reveal` blocks, `hero-in` / `line` + `line-inner` for hero text, `prose-v` for long-form (blog/legal).

## 6. SEO / AEO / GEO rules (do not regress)
- One `<h1>` per page; headings never skip levels (use `sr-only` h2 if needed). Titles ≤ 62 chars, meta descriptions ≤ 160 (build.py asserts this). Unique title/description per page.
- Home H1 contains the keyword inside it ("Web design & development company in Pune").
- **Answer-first copy:** first sentence of a section/FAQ answer is the direct answer. Keep `#hero-answer` and `#glance-answer` (marked `speakable`).
- **JSON-LD** per page via `build.py`: `WebSite`, `ProfessionalService` (full on home/about/contact), `WebPage` variants, `BreadcrumbList`, `Service` (service pages), `FAQPage` (faq + service pages), `BlogPosting` (articles), `ItemList` (hubs). **FAQ schema text must match visible text exactly** (generated from the same data, so edit only in `content.py`).
- Visible breadcrumbs on all inner pages. Descriptive anchor text; every service page links to related work, other services, and contact.
- Canonical per page (home = bare domain), `hreflang en-IN`, geo meta, OG/Twitter tags, `robots` meta; 404 is `noindex`.
- Images: `width`/`height` + descriptive `alt` + `loading="lazy"`.
- `robots.txt` allows all crawlers (incl. AI search bots); `llms.txt` summarises site for AI tools. `sitemap.xml` lists the 17 indexable URLs.
- No fake reviews, no review/rating schema until real reviews exist.

## 9. Decisions log
- Moved from single page to multi-page for SEO (one URL per service/topic) and internal linking.
- Replaced Tailwind CDN with a compiled CSS file (faster LCP, no runtime compile). Font Awesome still loads from CDN.
- Static generator in Python instead of a framework: zero dependencies at runtime, easy to host, copy lives in one data file.
- Contact form opens a pre-filled WhatsApp message (no backend). Swap for Formspree/Netlify Forms/API if email capture is wanted.
- Preloader shown once per session via `sessionStorage` key `vlx`; skipped for reduced-motion and bots.
- Testimonials section removed rather than shipping invented quotes.
